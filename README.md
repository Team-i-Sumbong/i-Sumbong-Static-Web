Proposal 1 — GalaSa Aguilar (Tourism Website Project)
----------------------------------------------------
- Description: GalaSa Aguilar is a web-based tourism guide to help users discover tourist spots, local attractions, and travel information in the Philippines. It provides organized destination details, images, and travel tips on an accessible platform.
- Goals: Promote local tourism while making travel planning simple, fast, and user-friendly.

- Possible Contents:
  - Complete information about tourist spots
  - Search and filter destinations
  - Promote local tourism in the city
  - Showcase destinations with images and descriptions
  - Local food and delicacies

- Possible Features:
  - User login page (save favorites, personalization)
  - Navigation bar (Home, Attractions, Map, Tips, Contact)
  - Search & filter by category, barangay, or keyword
  - Tourist spot gallery (photos, description, location, fees, best time)
  - Interactive map with clickable markers (embedded/Google Maps)

- HCI Concepts:
  - Usability: simple, learnable flows for login and browsing
  - Consistency: uniform navigation, colors, buttons
  - Efficiency of use: search & filter to reduce time-to-info
  - Aesthetic & minimalist design: avoid clutter, highlight content
  - Error prevention & handling: clear login errors and input validation

Proposal 2 — Overview of Common Career Pathways in IT
----------------------------------------------------
- Description: A structured webpage that presents common IT roles, skill areas, and progression patterns across the industry.

- Possible Contents:
  1. Introduction & scope
  2. Major IT career categories (Software, Web, Cybersecurity, Data, Network)
  3. Foundational knowledge areas (programming, data structures, networking)
  4. Skill progression model (foundational → intermediate → specialization)
  5. Tools & technology overview
  6. Industry context (entry-level roles, internships, portfolios)
  7. References (reports, job trends, surveys)

- Possible Features:
  - Clear navigation with anchors
  - Expandable sections (accordion)
  - Timeline-style skill progression
  - Responsive layout, scroll-to-top, basic filtering

- HCI Concepts:
  - Information hierarchy and consistent layout
  - Recognition over recall: clear labels and keywords
  - Progressive disclosure: expandable content
  - Accessibility: proper contrast and semantic HTML

Proposal 3 — Mystery Box (Random Challenge & Interaction Platform)
-----------------------------------------------------------------
- Description: An interactive platform that generates random prompts (questions/dares/challenges). Users can respond anonymously and view public responses.

- Possible Contents:
  - Home and explanation of Mystery Button behavior
  - Mystery Challenge page (random prompt generator)
  - Anonymous response form and public response wall
  - Daily featured challenge and privacy notice

- Possible Features:
  - Random prompt generator
  - Anonymous submissions and live response feed
  - Reaction emojis and simple moderation/filtering
  - Countdown timer and playful UI

- HCI Concepts:
  - Usability, Feedback, Error prevention (empty submissions), Accessibility
  - Minimalist but playful design, consistent controls, visibility of system status
