HTML

Document Structure

Boilerplate HTML

The starting template every HTML file needs.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
    content="width=device-width">
  <title>Page Title</title>
</head>
<body>
  <!-- content here -->
</body>
</html>
Meta Tags HTML

Metadata that goes inside <head>.

<meta charset="UTF-8">
<meta name="description"
  content="Page description">
<meta name="viewport"
  content="width=device-width,
  initial-scale=1.0">
<link rel="stylesheet" href="style.css">

CSS

Selectors

Common Selectors CSS

How to target elements in CSS.

h1 { }            /* element */
.box { }          /* class */
#hero { }         /* id */
h1, h2 { }        /* multiple */
div p { }         /* descendant */
div > p { }       /* direct child */
a:hover { }       /* pseudo-class */
p::first-line { } /* pseudo-element */
li:nth-child(2) { }
CSS Variables CSS

Reusable values defined with -- prefix.

/* Define in :root */
:root {
  --primary: #4D9FFF;
  --font-size: 16px;
  --radius: 8px;
}

/* Use with var() */
.button {
  background: var(--primary);
  border-radius: var(--radius);
}

Box Model

Spacing & Size CSS

Margin, padding, border, and sizing properties.

margin: 10px;           /* all sides */
margin: 10px 20px;      /* top/bottom, left/right */
margin-top: 10px;       /* single side */

padding: 16px;
padding: 10px 20px 10px 20px;

border: 1px solid #ccc;
border-radius: 8px;

width: 300px;
max-width: 100%;
box-sizing: border-box;
Display CSS

Controls how an element is rendered.

block Full width, new line
inline Stays in text flow
inline-block Inline but has width/height
flex Flexbox container
grid Grid container
none Hidden, removed from layout
Positioning CSS

Controls where elements are placed.

position: static;    /* default */
position: relative;  /* offset from normal */
position: absolute;  /* relative to parent */
position: fixed;     /* relative to viewport */
position: sticky;   /* scrolls then sticks */

top: 0;
left: 0;
z-index: 10;
CSS

Flexbox

Flex Container CSS

Properties applied to the parent flex container.

.container {
  display: flex;
  flex-direction: row;     /* or column */
  justify-content: center; /* main axis */
  align-items: center;    /* cross axis */
  flex-wrap: wrap;
  gap: 16px;
}
Justify & Align Values CSS

Common values for justify-content and align-items.

flex-start Pack to start
flex-end Pack to end
center Center items
space-between Even gaps, no edge space
space-around Equal space around items
stretch Fill cross axis (align-items)
Flex Items CSS

Properties applied to individual flex children.

.item {
  flex: 1;           /* grow and fill */
  flex-grow: 1;      /* how much to grow */
  flex-shrink: 0;    /* don't shrink */
  flex-basis: 200px; /* starting size */
  align-self: center;
  order: 2;
}

Media Queries CSS

Make your layout responsive for different screens.

/* Mobile first */
@media (min-width: 768px) {
  .container {
    flex-direction: row;
  }
}

/* Desktop first */
@media (max-width: 600px) {
  .nav {
    display: none;
  }
}
CSS

Effects & Animation

Transitions CSS

Smooth changes between states on hover or focus.

.button {
  background: #4D9FFF;
  transition: all 0.3s ease;
}

.button:hover {
  background: #FF6B35;
  transform: translateY(-2px);
  box-shadow: 0 8px 24px
    rgba(0,0,0,0.2);
}
Keyframe Animation CSS

Define and apply multi-step animations.

@keyframes fadeIn {
  from { opacity: 0; }
  to   { opacity: 1; }
}

.box {
  animation: fadeIn 0.5s ease;
  animation-delay: 0.2s;
  animation-iteration-count:
    infinite;
}
Shadow & Filter CSS

Visual depth and filter effects.

/* Box shadow */
box-shadow: 0 4px 20px
  rgba(0,0,0,0.3);

/* Text shadow */
text-shadow: 0 2px 4px
  rgba(0,0,0,0.5);

/* Filters */
filter: blur(4px);
filter: brightness(0.8);
opacity: 0.5;
