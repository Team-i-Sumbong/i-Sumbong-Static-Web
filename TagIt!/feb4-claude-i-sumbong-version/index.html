About the System

Community concerns, handled with care

i-Sumbong is a Java desktop application designed to streamline how barangay residents file and track community issues. From submitting a complaint with photo evidence to monitoring its resolution in real time — every step is clear, accountable, and digital.

Barangay officials gain a powerful dashboard to review, assign, and resolve reports — enabling faster response times and data-driven governance.

Features

Everything a barangay needs

Built for both residents and officials, with tools that make every report count.

🔐
User Registration & Login
Residents can securely create accounts and log in with role-based access — separate views for residents and barangay staff.
📋
Issue Reporting
Submit complaints with full details — category, location, description, and optional photo attachments for clearer documentation.
📡
Real-Time Status Tracking
Residents can monitor report progress from Pending → In Progress → Resolved with live status updates from officials.
🖥️
Admin Dashboard
Barangay staff get a centralized view to manage all submissions, assign actions, and update issue statuses efficiently.
🔍
Search & Filter
Quickly locate specific reports by filtering across category, current status, date range, or resident name.
📊
Report History & Analytics
Generate summaries and analytics of reported issues to support transparency and informed decision-making by officials.
How It Works

Four steps to resolution

From submission to resolution, every report follows a clear, trackable process.

01
Register & Log In
Resident creates a secure account on the desktop app to begin filing issues.
02
Submit a Report
Fill in details, select a category, mark the location, and attach supporting images.
03
Officials Review
Barangay admin reviews the submission, assigns actions, and updates the status.
04
Track & Resolve
Residents watch the progress until the issue is marked Resolved and closed.
